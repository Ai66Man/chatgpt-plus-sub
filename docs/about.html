关于本站：定位、比价口径、商业关系与资料核验方式

更新于 2026-10-13

本站做什么

本站只做一件事：把 ChatGPT、Claude、Gemini、Grok 以及主流 AI 编程工具的订阅放在一起比。比价格、比额度口径、比适合谁、比国内用户怎么开通。目标读者是准备第一次订 AI、或者正在考虑换一家、升一档的人。

本站不做单品充值页，不写单一产品的付款排查教程，也不提供跨区订阅或绕过地区限制的方法。这些内容要么属于各家官方帮助中心，要么属于服务商自己的站点。

比价口径

价格只写官方美元标价。所有价格取自各家官方定价页（OpenAI、Anthropic、Google、xAI、Cursor、GitHub 等），按官方标价原样记录，不含当地税费，不做汇率换算，也不转载任何商家的人民币报价。一个档位在官方页面上有多种计费方式时（如 Claude Pro 的月付与年付），两种都列出并注明。

额度只写计算方式，不写具体条数。各家对额度的描述口径不同：Claude 按滚动窗口，ChatGPT 按模型和功能分别限制，国内 Coding Plan 按积分或请求次数。官方会根据容量随时调整上限，而且不公布可长期依赖的数字，所以本站只描述「怎么算」，并引用官方的倍数说法（如「约为 Pro 的 5 倍用量」），不写任何「每 3 小时多少条」之类的具体数字。

能力对比写两面。每篇跨品牌对比都要同时写出各家的强项和短板，包括国内方案价格低、海外方案质量稳这类不利于导流的事实。只写一家好处的页面没有参考价值，也不会被当成可信的对比。

核对频率。官方价格每月 1 号核对一次，核对日期写在每页的表格说明和页脚；任何一家发布新模型或调价后 48 小时内更新价格表和对应对比文章。每篇文章的「更新于」日期表示最近一次实质内容修改，不会为了显得新而只改日期不改内容。

为什么不写人民币价格。人民币开通价是第三方服务商的报价，由商家自行定价，随成本和交付形态变动，与官方美元价不是固定汇率关系。写在本站上会很快过期，也容易被误当成官方价格。需要人民币报价时请直接到服务商页面查看当前价格。

商业关系披露

本站为 GoPlus 提供商业导流：页面中的「国内开通」入口会跳转到该第三方服务商及其小店页面，并带有来源标识参数（utm_campaign=ai66man_compare）。本站不销售、不开通任何订阅，也不收取任何款项；实际的开通、交付、退款与售后全部由该服务商负责，本站无法查询订单。

本站与 OpenAI、Anthropic、Google、xAI、Cursor、GitHub 均无隶属、合作或授权关系，也不是任何一家的官方网站。页面上引用的第三方服务说明均来自其公开页面，不构成本站的承诺。

不做什么

不提供跨区订阅或绕过地区限制的方法；不提供任何成功率、到账时间或质保承诺；不编造订单量、用户评价或成功案例；不收集任何账号凭据或支付信息。

怎么报错

发现价格过期、额度描述与官方不符、对比结论有误，可在 GitHub 仓库 Issues 反馈，请附页面地址、需要修正的表述和可核验的官方来源。确认后会在 7 天内修正并更新该页的「更新于」日期。请不要在反馈中提交订单、账号或支付资料。

订阅还是按量付费

订阅的优点是成本可预测，缺点是用不满就是浪费。按量付费（API）的优点是用多少付多少，缺点是重度使用时账单可能远超订阅。

大致的分界线：如果你每天稳定使用，订阅几乎总是更便宜；如果使用极不规律——某几天跑满、其余时间不碰——按量付费可能更合适。混合方案也常见：订一个基础档覆盖日常，突发的大任务走 API。

容易被忽略的隐性成本

  1. 额度耗尽后的等待。被打断半小时的成本，往往高于升级一档的差价。
  2. 多工具重复付费。同时订 Cursor 和 Claude Pro，代理能力是重叠的。
  3. 促销续费差价。国内套餐首月低价、次月回标价的情况常见。
  4. 税费与汇率。海外订阅的实际扣款高于标价。

按年算总账会看到什么

把月费乘以 12，数字会更有冲击力，也更容易做决定：

  • 每月 20 美元 = 一年 240 美元，约合 1,700 元。
  • 每月 100 美元 = 一年 1,200 美元，约合 8,500 元。
  • 每月 200 美元 = 一年 2,400 美元，约合 17,000 元。
  • 国内入门档每月 50 元 = 一年 600 元。

对个人开发者来说，20 美元档相当于每天 5 元多，几乎不需要犹豫；100 美元档一年接近一台笔记本的价格，就需要认真算产出了。

判断标准可以很简单：如果这个工具每周能帮你省下 3 小时以上的实际工作时间，100 美元档在绝大多数地区都是划算的。省不到，就说明问题不在档位，在使用方式。

什么时候应该降档

升级的讨论很多，降档几乎没人讲，但它同样能省钱。出现下面任意两种情况，就该考虑降回去：

  1. 连续两个月没有再撞到额度上限。
  2. 工作重心从写代码转向了会议、设计或者其他事务。
  3. 项目进入维护期，日常改动量明显下降。
  4. 已经把常规任务分流给了更便宜的方案，高档位只是偶尔用。

订阅都是按月的，降档随时可以做，而且通常在当前账期结束后生效，不会浪费已付的时间。把「每季度回顾一次档位」变成习惯，一年能省下不少。

SAFETY

开通需要提供什么

不同产品要的东西不一样，但都不需要你的密码。

产品开通需要提供这是什么不需要提供
ChatGPTSession在已登录状态下获取。它具有账号访问能力，开通完成后退出重新登录即可重置。不需要密码、不需要短信验证码
ClaudeOrganization ID在 Settings → Account 里可以查到，本身不能用于登录你的账号。不需要登录你的账号，避免触发风控
GrokUserID账号标识，不是登录凭据，可在账号会话信息里查到。不需要密码，只要一个 ID

这一步是整个流程里最该问清楚的地方，所以写在明面上：

  • 不需要账号密码，不需要邮箱密码，不需要短信验证码。
  • ChatGPT 的 Session 确实具有账号访问能力，属于敏感凭据；开通完成后在设置里退出重新登录即可重置。
  • Claude 的 Organization ID、Grok 的 UserID 都只是标识，拿到也无法登录你的账号。
  • 不要在任何聊天群、公开截图或来路不明的页面里提交这些信息。

如果你无法接受提交 Session，可以先看开通方式对比里不经过第三方的几条路径。

FAQ

开通前常见问题

最容易卡住的几个问题，先看完再决定下单还是咨询。

这是官方订阅吗？

是开通在你自己的账号上，同步官方会员权益，可以在账号里看到明确的开通与到期时间。不是共享号或成品号。

需要海外信用卡吗？

不需要，微信、支付宝直接付款。这类服务解决的就是国内没有境外卡、或者银行卡频繁被拒的情况。

需要提供账号密码吗？

不需要密码，也不需要短信验证码。不同产品需要的信息不同：ChatGPT 需要 Session，Claude 需要 Organization ID，Grok 需要 UserID。Session 具有账号访问能力，开通完成后退出重新登录即可重置。

Plus 和 Pro 5X / 20X 怎么选？

日常写作、学习、办公和轻量编程选 Plus。每天高频跑 Codex、深度研究或长文档任务，再考虑 Pro 5X / 20X。

Claude Pro 和 Max 怎么选？

先用 Pro。如果每天长时间使用 Claude Code、经常触及用量上限，再升 Max 5X；全天候多任务并行才需要 20X。

多久到账，售后找谁？

基础档小店下单后按页面引导提交信息即可，高配档由人工确认后交付。到账、异常与售后均由 GoPlus 处理，请保留订单号与沟通记录。

售后政策是怎样的？

按 GoPlus 公布的说明为全程质保不掉订阅；封号不在质保范围内，因为封号通常与使用环境或使用行为有关。具体条款以下单时页面为准。
